# Specifications

Эта папка хранит технические спецификации.

## Что должна содержать спецификация

Минимум:

1. Проблема и контекст
2. Цели и не-цели
3. Изменяемые файлы и модули
4. Изменения API/tool-set
5. Acceptance criteria
6. План верификации
7. Какие документы надо обновить

## Рекомендуемый формат имени

```text
SNN_short_snake_case_name.md
```

Примеры:

- `S01_restore_actions_tools.md`
- `S02_add_card_comment_read_tool.md`

Для шаблона и правил оформления см. [../4. guides/specifications_guide.md](../4.%20guides/specifications_guide.md).
