# Документация проекта

Эта папка хранит рабочую документацию по проекту: handoff, changelog, гайды, будущие спеки и исследовательские заметки.

## Структура

| Путь | Назначение |
| --- | --- |
| `HANDOFF.md` | Точка входа: текущее состояние, важные ограничения, следующие шаги |
| `CHANGELOG.md` | Журнал заметных изменений в коде и документации |
| `1. business requirements/` | Бизнес-запросы и исходные требования |
| `2. specifications/` | Технические спецификации и RFC |
| `3. tasks/` | Активные задачи и архив завершенных/проваленных |
| `4. guides/` | Операционные гайды по этому репозиторию |
| `5. unsorted/` | Исследования, временные записки, внешние артефакты |
| `6. backlog/` | Отложенные идеи и задачи вне активного плана |

## С чего начинать

1. Прочитать [HANDOFF.md](HANDOFF.md).
2. Если нужен исторический контекст по tool-set, открыть [2026-04-02_trello_mcp_history_and_tool_gap_analysis.md](5.%20unsorted/2026-04-02_trello_mcp_history_and_tool_gap_analysis.md).
3. Для правил оформления и обновления документации смотреть [4. guides/doc_conventions.md](4.%20guides/doc_conventions.md).
4. Для кода и запуска смотреть [../README.md](../README.md) и [../ARCHITECTURE.md](../ARCHITECTURE.md).
