# Business Requirements

Эта папка предназначена для исходных бизнес-запросов.

## Что хранить здесь

- запросы владельца продукта
- описания use case
- ограничения со стороны пользователей и MCP-клиентов
- обоснование, зачем нужен тот или иной tool / capability

## Рекомендуемый формат имени

```text
BRNN_short_snake_case_name.md
```

Примеры:

- `BR01_restore_actions_api_surface.md`
- `BR02_card_comment_reading_for_agents.md`

Если требований пока нет, не придумывайте их задним числом. Сначала можно оформить исследовательскую заметку в `5. unsorted/`, а затем превратить ее в formal BR.
